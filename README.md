# 教师智能备课与课件生产 Skill V1.4.1（合并版）

**定位：全局、低门槛、跨Agent、双路由。**

> V1.4.1 = V1.4 的视觉素材双路由 + 第3次课实测后的“课件生成器由教师点选”修正 + 完整的参考规则与模板。详见《版本说明_V1.4.1_合并版.md》。

V1.4 在 V1.3 的基础上重点解决一个实际问题：

> 有些Agent能备课、能做PPT，但不能生成图片。视觉核心素材怎么办？

新版答案是：**视觉素材生成器也做成可插拔后端。**

- 当前Agent能生图：自动生成。
- 当前Agent能调用已授权图像工具：自动调用。
- 当前Agent完全不能生图：自动产出一个完整的“视觉素材生产任务包”，教师只需整体上传给支持生图的Agent一次。
- 图片完成后整体回传，原Agent自动验收并继续做PPT。

**不再让老师逐条复制十几条提示词。**

## 老师平时只需要会说

- “帮我备《XX》这节课，整套做完。”
- “继续做这节课，把剩下的完成。”
- “根据现有材料把PPT做出来。”
- “根据最终PPT给我写逐字授课稿。”
- 在生图Agent里：“按这个视觉素材任务包，把全部核心图片一次性做完并打包。”

## 两条可插拔路由

1. **视觉素材生成器路由**（自动）：原生生图 / 图像Skill / 外部图像服务 / 一次性交接任务包。
2. **课件生成器路由**（教师点选一次，之后沿用）：PPT Master / PowerPoint / Canva / Figma Slides / HTML / 其他。交付时写明用了哪个、为什么。

上游教学设计不绑定任何单一平台。

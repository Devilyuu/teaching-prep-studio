# Skill 评测清单

## 低门槛
- [ ] 老师一句“整套做完”可触发完整流程
- [ ] 不要求老师记阶段编号
- [ ] 不要求老师列文件路径

## 无生图Agent场景
- [ ] 能识别当前无生图能力
- [ ] 自动生成完整视觉素材生产任务包
- [ ] 没有要求老师逐条复制提示词
- [ ] 生图结果回流后能自动验收
- [ ] 验收合格后能从断点继续

## 生图Agent接力场景
- [ ] 收到任务包后不重做教案
- [ ] 按任务编号批量生产
- [ ] 保留文件名
- [ ] 输出完成包和验收记录

## 视觉素材场景（V1.6）
- [ ] 界面、图表、示意图类素材走程序化渲染，不送生图模型
- [ ] 程序化渲染源文件存 视觉素材/源文件/ 并登记进课程素材源文件库
- [ ] 标注类图逐张目检，标签不压主体、不互压、不出画布
- [ ] B类真实截图注明截图日期与账号状态
- [ ] 学生课上要打开修改的起步文件在阶段 4 列为 E 类并定来源
- [ ] 做不出可编辑起步文件时生成教师课前准备清单并估时，流程不暂停
- [ ] 不用导入图片/SVG 冒充可编辑文件

## PPT场景
- [ ] 不固定绑定PPT Master
- [ ] 能根据环境选择课件生成器，教师点选一次后沿用
- [ ] 生成器有多条路线时按规则选直出或带确认门，交付说明写明
- [ ] 生成器不出逐页预览时用兜底方式导出，先看总览图再看关键页
- [ ] PPT生成后执行视觉QA，质量报告有检查记录
- [ ] 演讲者备注以课件内为准，09 文件为副本并注明

## 讲稿场景
- [ ] 逐字稿基于最终课件
- [ ] 页码与内容逐页一致
- [ ] 实践时段不是连续口播

## 教学实施材料（V1.6）
- [ ] 任务简报写了上一课预告及偏差处理、班额对策（>40 人）
- [ ] 验收课有单元项目评价表，维度与总控档案一致，有课上硬条件与补交规则
- [ ] 软件操作类课程的演示脚本写了版本号、核对日期、替代路径与常见现场问题
- [ ] 教师课前待办带估时，交付说明开头醒目列出

## 质量
- [ ] 有课程总控档案
- [ ] 有单课进度档案
- [ ] 有双重质量检查
- [ ] 总分低于85不作为正式成品交付

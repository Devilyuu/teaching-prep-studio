# Skill 评测清单

## 低门槛
- [ ] 老师一句“整套做完”可触发完整流程
- [ ] 不要求老师记阶段编号
- [ ] 不要求老师列文件路径

## 无生图Agent场景
- [ ] 能识别当前无生图能力
- [ ] 自动生成完整视觉素材生产任务包
- [ ] 没有要求老师逐条复制提示词
- [ ] 生图结果回流后能自动验收
- [ ] 验收合格后能从断点继续

## 生图Agent接力场景
- [ ] 收到任务包后不重做教案
- [ ] 按任务编号批量生产
- [ ] 保留文件名
- [ ] 输出完成包和验收记录

## PPT场景
- [ ] 不固定绑定PPT Master
- [ ] 能根据环境选择课件生成器
- [ ] PPT生成后执行视觉QA

## 讲稿场景
- [ ] 逐字稿基于最终课件
- [ ] 页码与内容逐页一致
- [ ] 实践时段不是连续口播

## 质量
- [ ] 有课程总控档案
- [ ] 有单课进度档案
- [ ] 有双重质量检查
- [ ] 总分低于85不作为正式成品交付

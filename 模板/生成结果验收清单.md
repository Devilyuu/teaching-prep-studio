# 生成结果验收清单

## 一、视觉素材完成包验收

逐项检查：

- [ ] 所有任务编号均有对应文件
- [ ] 文件名与任务清单一致
- [ ] 图片比例符合要求
- [ ] 清晰度满足PPT大屏使用
- [ ] 同一主体保持视觉一致性
- [ ] Logo/关键识别点未漂移
- [ ] 错误案例保留指定错误
- [ ] 不含意外乱码或无关文字
- [ ] 构图适合对应PPT页面
- [ ] 不存在明显重复或低价值图片
- [ ] 标注类图：标签不压主体、不互压、不出画布、文字不溢出框
- [ ] B类真实截图已注明出处、截图日期与账号状态

## 二、课件完成包验收（交接场景）

从 PPT Master 类生成器回传 `课件完成包.zip` 后逐项检查：

- [ ] 页数与《课件生产清单》一致，无漏页错页
- [ ] 页序未被擅自调整
- [ ] 图片无拉伸变形，裁切未切掉主体
- [ ] 占位图已全部替换为真实素材
- [ ] 图文对应，讲哪张图放哪张图
- [ ] 每页有可辨视觉层次，不是整页平铺文字
- [ ] 配色遵循《课程PPT视觉规范》
- [ ] 文字不叠压、不溢出版面
- [ ] 演讲者备注已写入（或另附）
- [ ] 故意设置的错误案例未被"修正"
- [ ] 教学内容、目标、任务标准未被改动
- [ ] 源文件可编辑，导出文件能正常打开

未通过项按页号列出，形成返工清单再交一次，不含糊放行。

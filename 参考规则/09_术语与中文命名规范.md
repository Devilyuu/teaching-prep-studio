# 术语与中文命名规范

面向教师的文件和界面优先使用中文。

| 原英文概念 | 本 Skill 中文名称 |
|---|---|
| Course Passport | 课程总控档案 |
| Lesson State | 单课进度档案 |
| Lesson Brief | 单课任务简报 |
| Slide Outline | PPT页面大纲 |
| Presentation Manifest | 课件生产清单 |
| Assets Manifest | 视觉素材清单 |
| Renderer | 课件生成器 |
| Renderer Handoff | 课件生成器任务书 |
| Gate | 阶段验收 |
| Visual QA | 视觉质量检查 |
| Teaching QA | 教学质量检查 |
| Quality Anchor | 质量样板课 / 质量锚点 |
| Identity Sheet | 视觉识别基准 |
| Teaching Package | 教学实施包 / 完整备课包 |
| Brief | 任务简报 |
| Speaker Notes | 演讲者备注 |
| Image Generator / Image Backend | 视觉素材生成器 |
| Image Task Package | 视觉素材生产任务包 |
| Image Task Manifest | 视觉素材任务清单 |
| Image Delivery Package | 视觉素材完成包 |
| Handoff | 交接 |
| Routing | 路由（面向教师时说“自动选择合适的方式”） |

## 保留英文的情况

以下情况可以保留英文：

- `SKILL.md` 文件名（兼容Skill系统）
- 内部 Skill ID：`teaching-prep-studio`
- 已成为专业通用表达的工具/软件名
- 教师明确要求双语

其他面向教师的名称默认中文优先。

# 视觉素材分类与生产规范

## 一、视觉资产不是装饰

每张图至少服务于一种教学目的：

- 观察
- 对比
- 诊断
- 示范
- 解释
- 任务提示
- 评价

如果一张图只为了"页面不空"，应优先删除。

## 二、先分类，再决定怎么来

### A 教师已有素材

优先复用，检查清晰度、版权/使用条件与教学适配性。

### B 真实资料/真实案例

历史照片、文物、企业案例、真实界面、真实产品、数据等。优先检索可信来源并写明出处，不用AI生成内容冒充事实。

来源可以是：教师提供、检索引用、脚本抓取公开页面、**学生作业**（需征得同意、匿名、默认只投影不进课件，清单里写"B（学生提供）"）。

真实界面/网页截图必须记录：**截图日期、登录/账号状态**（未登录空状态、已登录示例账号等）、**是否含个人信息**（须脱敏）。课件页注明产品名、截图日期与状态。

### C 核心教学视觉（由 Agent 制作）

模拟案例、角色、产品标准图、错误案例、Before/After、过程对比、规格卡等。必须有明确教学目的。

**先判断能否程序化渲染**：界面、图表、结构性示意图、版式、规格卡优先用 HTML/SVG 渲染，像素级可控、可出多版本、可同源导出规格表；生图模型只用于场景、角色、材质、照片感、插画感。路由见《03_视觉素材生成器路由》。

### D 课件内生信息图形

流程图、时间线、对照表、评价标准、任务结构、箭头关系等，优先由PPT/Slides生成器原生绘制，保持可编辑，不浪费生图模型。

### E 软件内起步文件（学生课堂操作对象）｜V1.6 新增

**定义**：学生要在某个软件里**打开并修改**的对象——设计软件文件（Figma / PS / AI / 即时设计等）、工程文件（视频、3D、音频、代码工程）、代码起步骨架、数据集、表格模板、文档模板。它不是图片，**截图不能代替它**。

**识别时点：阶段 4**，与图片一起写进视觉素材清单（分类 E）。不得等到阶段 5 才发现做不出来。

**来源三选一**，清单里写明：

1. **环境直接生成**：HTML/代码骨架、CSV、Markdown 模板、可导入的标准格式（须确认目标软件导入后仍可编辑）→ 放 `视觉素材/起步文件/`；
2. **程序化导出规格表，教师复现**：环境做不出可编辑格式，但能从同一源文件导出元素坐标、尺寸、颜色、字号、图层清单 → 生成 `06_教师课前准备清单.md`（规格表 + 对照图 + 检查项），写明预估时长；
3. **教师自备**：教师已有文件、上一课示范副本、学生上一课产物 → 写明来源与整理动作（复制、改名、设权限）及预估时长。

**硬规则**：

- 不得用"导入图片 / SVG"冒充可编辑文件（例：SVG 导入 Figma 后文字变成矢量路径，学生改不了字号）；不确定时先核实目标软件的导入行为，再定来源方式；
- 每个 E 类物料写明**发放方式**（链接权限、复制到个人草稿、平台上传）和**学生取用步骤**，写进《学生任务书》；
- 《单课进度档案》"教师制作物料"单列并估时；只能由教师制作时**不暂停流程**，其他产物照做，交付说明里醒目列出；
- 起步文件里的"故意错误"与错误案例图来自同一源文件，数值一致。

避免"所有东西都让AI画"。

## 三、生成前五问

1. 这一页为什么需要图？
2. 是否已有真实素材更适合？
3. AI生成会不会让学生把虚构内容误当事实？
4. 哪些元素必须保持一致？
5. 这张图要让学生观察什么？

## 四、每个关键视觉素材的最低描述字段

- 素材编号
- 使用页面
- 教学目的
- 分类（A/B/C/D/E）
- 素材类型（正确案例 / 错误案例 / 中性示例 / 过程图 / 信息图 / 真实案例 / 起步文件）
- 主体
- 构图
- 比例
- 视觉风格
- 必须固定项
- 允许变化项
- 是否允许文字
- 清晰度要求
- 来源方式（教师提供 / 检索引用 / 学生提供 / 程序化渲染 / AI生成 / 课件生成器原生绘制 / 环境直接生成 / 规格表教师复现 / 教师自备）
- 源文件（程序化渲染与 E 类必填）
- 目标文件名
- 当前状态
- B类追加：出处、截图日期、账号状态、个人信息处理
- E类追加：目标软件与版本、发放方式、预估教师时长

## 五、视觉识别基准

涉及同一产品、角色、品牌、场景、物件时，应维护统一基准：

- 比例
- 结构
- 核心识别点
- 标志/Logo
- 标准色
- 材质
- 角色DNA
- 允许变化项
- 禁止变化项

设计类课程的模拟产品，识别基准同时就是它的 token 表（颜色、字号、间距、圆角命名与数值），程序化渲染与学生要建的变量用同一份。

## 六、错误案例

错误案例应满足：

> **看起来仍然有吸引力、整体仍像专业作品，但错误清晰、真实、可诊断。**

不要为了表现"错误"而故意生成低质量丑图。任何下游生成器（生图Agent或课件生成器）都不得把故意保留的错误"自动修正确"。

## 七、质量验收（每张素材通过后才记"已核验"）｜V1.6 新增

通用：

- 清晰度满足投影（界面类 2 倍图）；比例与清单一致；同一主体跨图一致；教学用途一眼可辨；
- 错误案例的错误处数与清单一致，没有被顺手修正；
- 不含意外乱码、占位文字、无关水印。

标注类图（叠加编号框、连线、尺寸线、色块的图）：

- 标签不压主体、标签之间不互压、不出画布、文字不溢出框；
- 标注坐标由测量得出，不手填；
- **首轮几乎必有重叠**（实测 9 张里 7 张返工），渲染后必须逐张目检，不能只看脚本跑通；
- 返工只改出问题的那张、那处。

程序化渲染类：

- 源文件已存 `视觉素材/源文件/`，脚本可重跑；
- 从同一源导出的规格表 / 数据表与图一致。

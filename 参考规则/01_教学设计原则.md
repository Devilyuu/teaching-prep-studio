# 教学设计原则

## 1. 建构性对齐

每一个学习目标至少对应：

- 一个学习活动
- 一个可观察的评价证据

避免：目标写“会分析”，课堂却只有教师讲授；目标写“会操作”，却没有实践产出。

## 2. 认知负荷

- 一次不要引入过多新概念。
- 复杂项目拆成若干阶段成果。
- 优先“示例 → 观察 → 总结”，再进入抽象规则。
- 新手适当提供完整示范，熟练后逐步撤掉脚手架。

## 3. 形成性评价

优先使用：

- 找错误
- 做对比
- 快速解释
- 中途检查
- 同伴互评
- 版本迭代
- 现场展示

评价不只发生在课程最后。

## 4. 项目制课程

项目不是“布置一个大作业”。

一个可教的项目至少包含：

> 任务简报 → 约束 → 里程碑 → 阶段验收 → 反馈 → 修改 → 展示/归档

## 5. 职业教育 / 实践课

优先：

- 接近真实工作流程
- 明确交付标准
- 强调规范
- 强调版本修改
- 强调过程证据
- 强调“能不能用于真实场景”

## 6. 教师示范

示范不是炫技。

好的示范应包含：

> 第一版 → 出现问题 → 诊断 → 修改 → 第二版 → 总结方法

让学生看到“判断过程”，而不是只看到最终结果。

## 7. 时间与课件的角色

- 先目标、再证据、再活动。
- 不以“老师讲完”为目标，以学生发生可观察的学习行为为目标。
- 实践课学生实践时间应明显高于教师连续讲授时间。
- 既使用正确案例，也使用可诊断的错误案例。
- PPT是课堂节奏控制器，不是教案全文。

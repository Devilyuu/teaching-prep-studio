# 课件逐页预览导出（阶段 8 视觉目检的兜底做法）

## 为什么需要

阶段 8 要求"支持逐页预览的生成器必须逐页目检后再交付"。但不少生成器（含 PPT Master）只导出 PPTX，不出逐页 PNG。没有预览就没法目检，"0 阻断 0 警告"只是生成器的自检，不等于投影上没问题。

2026-09 UI 课四次备课实测：用本机 PowerPoint 逐页导出 1920×1080 PNG，再拼一张总览图，先看整体再看关键页原图，每课都抓到了生成器自检抓不到的问题（细字偏小、并列页同构、图片与标题距离），四次复用稳定。

## 标准流程

1. 导出逐页 PNG 到 `课件/逐页预览/`（`slide_01.png` … `slide_NN.png`）；
2. 拼总览图 `课件/逐页预览/_contact_sheet.png`；
3. **先看总览图**：页面节奏是否有变化、配色是否遵循视觉规范、有没有明显溢出与空页、连续同构页是否有意为之；
4. **再看关键页原图**：封面、核心案例页、正误对比页、任务看板页、含细字的规格页；
5. 问题按页号写进《质量检查报告》第二节，只返工出问题的页；
6. 《单课进度档案》`课件生成.逐页预览` 登记目录路径。

## Windows（本机有 PowerPoint）

用本目录的 `导出逐页预览_Windows.ps1`，以只读、无窗口方式打开，不改动课件：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File "<Skill目录>/适配器/导出逐页预览_Windows.ps1" -Pptx "<课件.pptx>" -OutDir "<课次目录>/课件/逐页预览"
```

核心只有一句 COM 调用：`$pres.Slides.Item($i).Export($path, "PNG", 1920, 1080)`。

## macOS / Linux（无 PowerPoint）

- 有 Keynote：用 Keynote 打开 PPTX，导出 PDF，再用 `pdftoppm -png -r 110 课件.pdf slide` 转成逐页 PNG；
- 有 LibreOffice：`soffice --headless --convert-to pdf 课件.pptx`，再 `pdftoppm` 转图；
- 只有 Python：`pip install pdf2image` 后从 PDF 转图（仍需先得到 PDF）。

LibreOffice 渲染中文字体可能与 PowerPoint 有差异，只用来查版式与溢出，字体细节以 PowerPoint 为准。

## 拼总览图

```bash
python "<Skill目录>/适配器/拼总览图.py" "<课次目录>/课件/逐页预览" --cols 5 --thumb 400
```

依赖 Pillow。每页下方标页码与文件名，方便在报告里按页号指问题。

## HTML 演示类生成器

用无头浏览器逐页截图（Playwright：打开演示 URL，按页翻、`page.screenshot`），命名同上，再拼总览图。
